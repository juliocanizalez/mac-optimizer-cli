# Code of Conduct

## The short version

Be decent. Don't be a jerk. That's it.

## The slightly longer version

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Expected behaviour: be respectful, assume good intent, give constructive feedback.

Unacceptable behaviour: harassment, personal attacks, trolling, publishing others' private information.

## Enforcement

Report issues to [julio@nlc.com](mailto:julio@nlc.com). Reports will be reviewed and responded to. Violations may result in a temporary or permanent ban.
